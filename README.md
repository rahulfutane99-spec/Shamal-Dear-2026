# Shamal Birthday Website ❤️

A romantic, multi-page birthday website made for Shamal.

## What's included

- `index.html` — Home page
- `memories.html` — Nine-photo slideshow with an individual note for every photo
- `quiz.html` — Love quiz
- `letter.html` — Birthday letter
- `surprise.html` — Final birthday surprise
- `style.css` — Responsive pink-and-gold styling
- `script.js` — Slideshow, quiz, and birthday music controls
- `memory-01.jpg` through `memory-09.jpg` — Photos used directly by the slideshow (kept at the repository root to avoid folder-path issues)
- `assets/` — Original optimized photo copies and the birthday instrumental
- `.nojekyll` — Keeps GitHub Pages from applying Jekyll processing

## Create a new GitHub repository

1. Download and extract this ZIP on your computer.
2. On GitHub, create a **New repository** (for example, `Shamal-Birthday`).
3. Open the new repository and choose **Add file → Upload files**.
4. Upload **all extracted contents directly into the repository root** (the five HTML files, nine `memory-XX.jpg` files, CSS, JS, README, `.nojekyll`, `favicon.svg`, and the `assets` folder). Do not put them inside an extra parent folder and do not upload only the ZIP.
5. Commit the upload to the `main` branch.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch **main** and folder **/(root)**, then click **Save**.
9. Wait for GitHub Pages to publish. Your site URL will be shown in the Pages settings.

## Preview locally

Open `index.html` in a browser. Navigate through Home → Memories → Love Quiz → Letter → Surprise.

## Music note

Tap **Play birthday music** to start the included original instrumental. Browsers generally require a visitor interaction before audio can play.

## Editing

- Edit the captions in `memories.html`.
- Replace photos in `assets/` and update the corresponding image filenames in `memories.html`.
- Keep the folder structure intact when uploading to GitHub.
